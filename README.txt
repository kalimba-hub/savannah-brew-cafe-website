SAVANNA BREW CAFÉ — HTML & CSS ASSIGNMENT
========================================

PROJECT CONTENTS
- index.html       Home page
- about.html       About Us page and café story
- menu.html        Menu page with three KES price tables
- gallery.html     Gallery page with eight photographs
- contact.html     Contact details, opening-hours table, enquiry form and reservation form
- css/style.css    One shared external CSS stylesheet
- images/          Logo and local café/food photo assets

HOW TO OPEN THE WEBSITE
1. Extract the ZIP file to a folder on your computer.
2. Open Visual Studio Code.
3. Select File > Open Folder and choose the extracted "savanna-brew" folder.
4. In the Explorer panel, open index.html.
5. Right-click index.html and choose "Open with Live Server" if you have the Live Server
   extension installed. Otherwise, open the file directly in Chrome or Microsoft Edge.
6. Use the navigation bar to open all five pages and check that the links and images work.

IMAGE NOTE
The project includes locally stored AI-generated café and food photographs prepared for this
website. The logo is an SVG image. No image needs to be downloaded separately for the pages
to display. Google Fonts are optional; Georgia and Arial fallbacks are included in the CSS.

IMPORTANT FORM NOTE
The enquiry and reservation forms demonstrate the required HTML controls and browser-side
required-field validation. They do not send, store or confirm submissions because the assignment
uses HTML and CSS only and does not provide a server-side form handler. A real café would need a
backend service or a form-processing provider to receive these submissions.

VALIDATION AND FINAL SUBMISSION
The HTML structure, local navigation targets, image paths, alt text, required form fields and key
assignment features have been checked locally. Before submitting, also run each HTML file through
the W3C Markup Validator (https://validator.w3.org/) and the stylesheet through the W3C CSS
Validator (https://jigsaw.w3.org/css-validator/). Use the File Upload option for files on your
computer and record any warnings or errors reported by the validators here:

- Local project checks: passed.
- W3C HTML validation: complete this check before submission and record the result.
- W3C CSS validation: complete this check before submission and record the result.
